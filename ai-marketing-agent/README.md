- `articles/` — 每日精读，每日一个文件，按日期命名

## 来源与推断的区分

- **有来源的**：12 篇文章的标题、来源、日期、链接，以及平台事实与数字（出处见 `framework.md` 与 `research-report.md`）；厂商自己报的提升数字均标注为官方口径。
